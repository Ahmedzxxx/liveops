## ⚙️ مميزات وقواعد المنظومة

### 1. دورة الجدولة العادلة (6-Week Latin Cycle)
* **الأسبوع:** يبدأ من الأحد وينتهي بالسبت.
* **إجازة الجمعة:** ثابتة أسبوعياً للـ 6 إيجنتس.
* **باقي الأيام (أحد - خميس + سبت):** دايماً **5 شغالين على الكيو و 1 إجازة**.
* **قاعدة عدم التكرار:** مستحيل أي إيجنت تاخد (خميس أو سبت) أسبوعين ورا بعض.
* **قاعدة البداية والنهاية:** الموظفة التي ينتهي أسبوعها بالسبت إجازة، **تبدأ الأسبوع الجديد بيوم عمل إجباري يوم الأحد** (منع جمعة+سبت+أحد).

### 2. لوحة الكيو المباشرة (Live Queue Board)
* رصد لحظي لحالة الفريق: *(على الكيو / في البريك / في ميتنج / إجازة)*.
* زرار للمدير: **[ إيقاف الكيو لميتنج / طارئ ]** لاحتساب وقت الاجتماعات عمل مدفوع دون التأثير على الكيو.
* عداد بريك تراكمي لكل إيجنت حتى 60 دقيقة يومياً مع فحص كسر البريك.

### 3. الحضور والتعويض الذكي (Late & Makeup Engine)
* ساعات الشفت: 10:00 ص إلى 7:00 م (9 ساعات متضمنة ساعة بريك).
* **استئذان معتمد:** يلغي التأخير فوراً.
* **تعويض التأخير:** لو الإيجنت وصلت متأخرة بدون إذن وكملت 9 ساعات على الكيو بعد 7:00 م، يتم إلغاء التأخير تلقائياً واحتساب الفائض كساعات عمل إضافية (Overtime).

### 4. الأجندة الرسمية لمصر والتقارير المالية
* رصد آلي للإجازات الرسمية المصرية لعام 2026.
* احتساب **2x Double Pay** للإجازات الوطنية والدينية.
* احتساب **3x Triple Pay** لأيام أعياد الفطر والأضحى.
* تصدير فوري بضغطة زرار لتقرير إكسيل منسق HR-ready (`.xlsx`).

### 5. بوت تيليجرام التفاعلي (Telegram Bot)
* إرسال إشعارات فورية بالاستئذانات والسوابات لموبايل المدير مع أزرار مباشرة `[✅ موافقة]` و `[❌ رفض]`.
* إدخال الـ Token و Chat ID مباشرة من صفحة الإعدادات في التطبيق.

## 🌐 كيفية الرفع أونلاين (Online Deployment)
يمكن رفع هذا التطبيق أونلاين مجاناً في 5 دقائق ليعمل برابط عام للتيم:
1. **Render.com / Railway.app**:
   - أنشئ Web Service جديدة واربط مجلد المشروع.
   - أمر التشغيل (Start Command): `uvicorn main:app --host 0.0.0.0 --port $PORT`
2. **سيرفر داخلي أو VPS**:
   - شغل `run_server.py` واجعل البورت 8050 متاحاً عبر الشبكة أو Nginx.
